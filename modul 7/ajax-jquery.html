AJAX dan jQuery

Apa itu AJAX?

AJAX (Asynchronous JavaScript and XML) adalah teknik yang memungkinkan halaman web berkomunikasi dengan server tanpa harus memuat ulang (reload) halaman. Data bisa dikirim dan diterima secara diam-diam di latar belakang.

Contoh penggunaan AJAX: pencarian Google yang menampilkan saran secara otomatis saat Anda mengetik.

Apa itu jQuery?

jQuery adalah library JavaScript yang menyederhanakan penulisan kode. Tugas yang biasanya membutuhkan banyak baris JavaScript bisa dilakukan dengan lebih singkat menggunakan jQuery.

Cara menyertakan jQuery:

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

Cara menggunakan jQuery:

// Vanilla JavaScript
document.getElementById("judul").style.color = "red";

// jQuery (lebih singkat)
$("#judul").css("color", "red");
